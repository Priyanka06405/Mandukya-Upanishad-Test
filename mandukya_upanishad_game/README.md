# Mandukya Upanishad Quiz Game

Flask quiz app with 50 MCQs.

Features:
- Registration: Name + Personal Number + Password
- 50 Mandukya Upanishad questions
- Random question order
- Random A/B/C/D answer positions for every attempt
- Automatic scoring
- One submission per participant
- Simple admin result dashboard
